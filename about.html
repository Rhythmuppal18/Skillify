Academic Self-Assessment Platform

CS Evaluation Engine

Designed as part of the Front End Engineering-II (FEE-II / 25CSE0203) project. Skillify combines timed quizzardry, 1v1 peer challenges, interactive line debugging, and instant skill analytics.

System Highlights

Architecture & Core Innovations

PURE FRONTEND

Zero Backend Server Overhead

Serializes scores, seeds, and times directly into URL hashes using Base64 (`btoa`). No database or server latency required!

INTERACTIVE

Line Debugging & Sequencing

Interactive code line clickers for finding bugs and HTML5 Drag & Drop for ordering complex SQL queries.

1v1 ARENA

Dual Progress HUD & QR Codes

Real-time split-screen progress bars comparing live users against simulated CyberBot AI or friend ghost targets via QR code.

PERSISTENCE

Local Score History

Saves score attempts and performance history locally in browser storage with instant review and clear history tools.
